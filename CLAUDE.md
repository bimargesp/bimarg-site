# CLAUDE.md — BIMARG Site

## Orquestación del Flujo de Trabajo

### 1. Modo Planificación por Defecto
- Entra en modo planificación para CUALQUIER tarea no trivial
- Si algo sale mal, PARA y vuelve a planificar de inmediato
- Escribe especificaciones detalladas por adelantado

### 2. Bucle de Automejora
- Tras cualquier corrección: actualiza tasks/lessons.md con el patrón aprendido
- Revisa las lecciones al inicio de cada sesión

### 3. Verificación antes de Finalizar
- Nunca marques una tarea como completa sin demostrar que funciona
- Pregúntate: "¿Aprobaría esto un ingeniero senior?"

### 4. Exige Elegancia
- Para cambios no triviales: pausa y pregunta "¿hay una forma más elegante?"
- Cero parches hacky

### 5. Gestión de Tareas
- Planificar primero: escribe el plan en tasks/todo.md
- Documentar resultados y capturar lecciones
